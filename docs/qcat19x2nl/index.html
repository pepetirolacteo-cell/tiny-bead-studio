How to start

  1. Read Chapters 1–6 of the main guide and gather your starter kit.
  2. Print the first bracelet chart and stitch it with the step-by-step walkthrough.
  3. Pick one pattern from the 50 Best-Selling Patterns and make it in your own colors.
  4. Use the Price Calculator and the Photos That Sell guide before you list your first piece.
